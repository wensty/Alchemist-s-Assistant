# Alchemist's Assistant Extension V3

附属模组依赖主模组提供的控制面板、目标选择、路径模拟、范围模拟、危险区和沼泽区计算。控制台内的问号说明用于解释每个开关的计算含义；下面补充具体操作方式。

## 操作方式

- 打开主模组功能面板后，附属模组的控制项会追加显示在同一个面板中。
- 手动控制配置共有 3 组，默认快捷键分别是 `LeftControl`、`LeftAlt`、`LeftShift`。按住其中一个快捷键时，慢速搅拌、慢速加水、慢速研磨、慢速加热和大批量酿造会使用对应配置组的速度或倍率；不按快捷键时使用原速和 1 倍酿造。
- `暂停自动控制` 默认快捷键是 `Z`。按住时会暂停自动制动速度，让慢速搅拌、慢速加水和慢速加热只受手动配置影响。
- 定量研磨开启后，把鼠标悬停在研杵上并右键点击，会把当前材料研磨进度直接设为“研磨目标”。
- 定量加热开启后，把鼠标悬停在风箱上并右键点击，会把当前加热进度直接设为“加热目标”。
- 大批量酿造开启后，在配方书中一次酿造数量大于 1 时，会按当前手动控制配置的“酿造倍率”放大数量；材料不足时不会放大。
- 自动控制相关功能通常需要先在主模组中选择目标效果或目标漩涡，并开启对应的路径曲线、效果范围、漩涡范围、危险点模拟或沼泽区模拟，否则附属模组可能没有足够数据进行制动。
