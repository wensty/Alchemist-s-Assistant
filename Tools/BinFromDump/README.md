# BinFromDump

Generate an `AlchAssV3` zone `.bin` file from a runtime collider dump.

The tool reads `RuntimeDumps/map_colliders_*.json`, expands selected map-space
colliders by the potion indicator radius, writes `Line`/`Arc` primitives, and
builds the same binary BVH layout used by `Function.LoadZoneFromBin`.

Vortex bins are intentionally different. `Vortex_Water.bin` and
`Vortex_Oil.bin` store only a compact circle list:

```text
int32 count
count * (float64 x, float64 y, float64 radius)
```

They do not contain a BVH. The runtime selects a vortex by checking the mouse
point against each circle, and all path/ladle-vortex intersections use direct
line-circle checks.

```powershell
python Tools\BinFromDump\generate_vortex_bin_from_dump.py `
  RuntimeDumps\map_colliders_Water_20260608_233506.json `
  AlchAssV3\Bins\Vortex_Water.bin
```

The script writes the compact circle list directly. The game maps checked so
far do not contain positions that can touch two vortices at the same time, so no
overlap guard is needed here.

## Example

```powershell
python Tools\BinFromDump\generate_bin_from_dump.py `
  RuntimeDumps\map_colliders_Water_20260608_233506.json `
  RuntimeDumps\Generated_Strong_Water_from_dump.bin
```

Default filtering includes collider paths containing `StrongDangerZoneContainer`.
Use repeated `--include` arguments for other zones:

```powershell
python Tools\BinFromDump\generate_bin_from_dump.py dump.json out.bin `
  --include SwampZoneContainer `
  --include StrongDangerZoneContainer
```

## CGAL SVG Diagram

Use `plot_cgal_bin.py` to render the actual `Line`/`Arc` boundaries generated by
`CgalBinBuilder`.  This is the preferred diagram for checking the preprocessed
boundary against a game screenshot.

```powershell
python Tools\BinFromDump\plot_cgal_bin.py `
  RuntimeDumps\map_colliders_Water_20260608_233506.json `
  RuntimeDumps\Generated_Strong_Water_cgal_boundary_filter_s002_extra001.bin `
  RuntimeDumps\cgal_boundary_water.svg
```

The SVG uses red for the CGAL-generated bin boundary, brown for raw selected
colliders, and defaults to an automatically fitted whole-base view. The current
indicator collider is not drawn by default; add `--include-indicator` when
debugging the current potion collision.

Use manual view parameters when a local contact boundary needs a close-up:

```powershell
python Tools\BinFromDump\plot_cgal_bin.py `
  dump.json out.bin RuntimeDumps\cgal_boundary_cluster.svg `
  --center-x 0.1 --center-y -9.35 --width 6.2 --height 3.8 `
  --include-indicator
```

The indicator radius defaults to `dump.indicatorCollider.radius`. Override it
for experiments:

```powershell
python Tools\BinFromDump\generate_bin_from_dump.py dump.json out.bin --radius 0.75
```

## Current Mode

The default `per-collider` mode uses analytic per-collider offsets:

- `CircleCollider2D`: emits an arc with `source radius + indicator radius`.
- `BoxCollider2D` / `PolygonCollider2D`: offsets edges and adds corner arcs.
- `EdgeCollider2D`: emits a capsule-like boundary around each segment.
- `CapsuleCollider2D`: approximates from dumped `mapBoxCorners`.

Use `CgalBinBuilder --mode boundary-filter` to keep only each merged cluster's
exterior boundary while preserving analytic line and arc primitives during the
analysis stage. This is the current preferred path for shipped
preprocessed `Bins/*.bin` files.

The `.summary.json` written next to the output records primitive counts and
warnings.
